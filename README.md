# FrontMaria

Aplicación cliente del proyecto **TiendaMariaMejorada**, desarrollada con propósitos educativos.

## Integraciones y Dependencias

* **Backend:** Provee la interfaz que consume la API REST de **BackendMaria**.
* **Base de Datos / Cloud:** Los datos son gestionados a través de Cloud Firestore en el proyecto Firebase **MariaArticulos**.
* **Gestión de Medios:** Fotografías y recursos visuales alojados dentro de los assets locales del proyecto.

---

## Requisitos Previos

* [Node.js](https://nodejs.org/) (versión LTS recomendada)
* Instancia en ejecución de **BackendMaria** (local o desplegada en Vercel)
